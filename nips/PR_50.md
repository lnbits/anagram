# PR #50 — Message editing

## What

Adds editing for a user's own text messages in direct and group chats. The composer enters edit mode without losing an existing draft, and updated messages display an "edited" label.

## How

Edits use NIP-17's delete-and-replace flow: the client sends a wrapped `kind:5` deletion for the previous event and a replacement wrapped `kind:14` rumor with the original timestamp and a private `e` tag marked `edit`. Persistence and ingest track previous event IDs and reconcile either relay arrival order, preventing duplicates while preserving replies, reactions, deletions, chat previews, backfill, and reload behavior.

## Testing

Includes unit and relay-backed e2e coverage for direct and group edits, draft preservation, duplicate prevention, reloads, and out-of-order delivery.
